PHASE 1 TESTING INSTRUCTIONS (Architecture & Database Schema)
ফেজ ১ টেস্টিং গাইডলাইন (আর্কিটেকচার ও ডাটাবেজ স্কিমা)
=========================================================

---------------------------------------------------------
STEP 1: Check Pre-requisites / পূর্বশর্তসমূহ চেক করা
---------------------------------------------------------
1. Java Development Kit (JDK 21+): java -version
2. Apache Maven: mvn -version
3. PostgreSQL Database / Supabase Cloud DB

---------------------------------------------------------
STEP 2: Setup Database (Native PostgreSQL or Supabase Cloud)
---------------------------------------------------------
Option A: Using Native Installed PostgreSQL (Local):
1. Start postgres server:
   pg_ctl -D /opt/homebrew/var/postgresql@1 start

2. Create database & user:
   createdb helpguru_db
   createuser -s postgres

Option B: Using Supabase Cloud DB (Active Configuration):
Backend is connected to Supabase Cloud DB via application.yml!

---------------------------------------------------------
STEP 3: Execute Database Migration Script / ডাটাবেজ মাইগ্রেশন রান করা
---------------------------------------------------------
Command / কমান্ড (via psql CLI to Supabase):
psql "postgresql://postgres.wrjwhiyomhlqlcuvxsgf:MuSfi0191Mu@aws-0-ap-southeast-1.pooler.supabase.com:5432/postgres" -f "helpguru-backend/src/main/resources/db/migration/V1__initial_schema.sql"

---------------------------------------------------------
STEP 4: Verify Database Tables & Seed Data / ডাটাবেজ ভেরিফিকেশন
---------------------------------------------------------
Query 1: List all 14 created tables / তৈরি হওয়া ১৪টি টেবিল দেখা
SELECT table_name FROM information_schema.tables WHERE table_schema = 'public' ORDER BY table_name;

Query 2: Check Seeded System Roles / সিস্টেম রোলসমূহ চেক করা
SELECT * FROM roles;

Query 3: Check Seeded Emergency Regions / জাতীয় জরুরি রিজিয়নসমূহ চেক করা
SELECT id, code, name, center_latitude, center_longitude FROM regions;

---------------------------------------------------------
STEP 5: Backend Compilation & Structure Verification / ব্যাকএন্ড কম্পাইলেশন চেক
---------------------------------------------------------
cd helpguru-backend
mvn clean compile

Expected Output / প্রত্যাশিত আউটপুট: [INFO] BUILD SUCCESS

=========================================================

PHASE 3 TESTING INSTRUCTIONS (Incident & Resource Management)
ফেজ ৩ টেস্টিং গাইডলাইন (ইনসিডেন্ট, রিসোর্স ও হসপিটাল মডিউল)
=========================================================

---------------------------------------------------------
STEP 1: Register Emergency Hospital Facility / হসপিটাল এন্ট্রি টেস্ট
---------------------------------------------------------
Run cURL to register a new Hospital Facility with bed & ICU capacity:
ব্রাউজার বা টার্মিনালে হাসপাতাল রেজিস্টার করতে কমান্ড দিন:

curl -X POST "http://localhost:8080/api/v1/hospitals" -H "Content-Type: application/json" -H "Authorization: Bearer <YOUR_JWT_TOKEN_HERE>" -d '{"name":"Barishal Medical College Hospital","code":"HOSP-BAR-01","regionId":2,"latitude":22.7010,"longitude":90.3535,"totalBeds":150,"availableBeds":120,"icuTotal":20,"icuAvailable":15,"emergencyContact":"+8801711112222"}'

Expected Output (HTTP 201 Created):
Hospital created with status OPERATIONAL and synced to Supabase DB.

---------------------------------------------------------
STEP 2: Register Emergency Resource Unit (Ambulance / Rescue Team) / রিসোর্স ইউনিট টেস্ট
---------------------------------------------------------
Run cURL to register an Emergency Responder Ambulance unit:
টার্মিনালে নতুন জরুরি অ্যাম্বুলেন্স রেজিস্টার করতে কমান্ড দিন:

curl -X POST "http://localhost:8080/api/v1/resources" -H "Content-Type: application/json" -H "Authorization: Bearer <YOUR_JWT_TOKEN_HERE>" -d '{"resourceCode":"AMB-BAR-01","name":"Barishal ICU Ambulance Unit 1","resourceType":"AMBULANCE","regionId":2,"hospitalId":1,"currentLatitude":22.7010,"currentLongitude":90.3535,"capacity":2,"speedKmh":75.0}'

Expected Output (HTTP 201 Created):
Resource created with status AVAILABLE and initial GPS log persisted.

---------------------------------------------------------
STEP 3: Report New Emergency Incident / জরুরি ইনসিডেন্ট রিপোর্টিং টেস্ট
---------------------------------------------------------
Run cURL to report a Critical Disaster Incident in Barishal Region:
জরুরি দুর্যোগ ঘটনা রিপোর্ট করতে কমান্ড দিন:

curl -X POST "http://localhost:8080/api/v1/incidents" -H "Content-Type: application/json" -H "Authorization: Bearer <YOUR_JWT_TOKEN_HERE>" -d '{"title":"Severe Flood & Landslide Trapped Victims","description":"Barishal coastal flood trapped 25 family members needing urgent rescue","severityLevel":9,"affectedPeopleCount":25,"timeSensitivityLevel":"CRITICAL","requiredResourceType":"AMBULANCE","regionId":2,"latitude":22.7050,"longitude":90.3580,"addressText":"Sadat Road, Barishal Sadar"}'

Expected Output (HTTP 201 Created):
Incident created with unique code INC-XXXX and status REPORTED.

---------------------------------------------------------
STEP 4: Update Live GPS Telemetry / জিপিএস ট্র্যাকিং আপডেট টেস্ট
---------------------------------------------------------
Run cURL to send live GPS coordinates and speed telemetry update from moving vehicle:
চলন্ত গাড়ি থেকে জিপিএস লোকেশন ও স্পিড আপডেট পাঠাতে কমান্ড দিন:

curl -X PATCH "http://localhost:8080/api/v1/resources/1/location" -H "Content-Type: application/json" -H "Authorization: Bearer <YOUR_JWT_TOKEN_HERE>" -d '{"latitude":22.7040,"longitude":90.3560,"speedKmh":82.5,"headingDegrees":45.0,"status":"DISPATCHED"}'

Expected Output (HTTP 200 OK):
Live GPS updated and persisted to telemetry log.

Returns ranked list of candidate emergency units with calculated distance (km), estimated ETA (mins), objective score (0-100), and nearest suitable hospital.

---------------------------------------------------------
Run cURL to dispatch Resource ID 1 (Ambulance) to Incident ID 1 & Hospital ID 1:
টার্মিনালে কমান্ড দিন:

curl -X POST "http://localhost:8080/api/v1/dispatch/assignments" -H "Content-Type: application/json" -H "Authorization: Bearer eyJhbGciOiJIUzM4NCJ9.eyJzdWIiOiJvcGVyYXRvcjEiLCJ1c2VySWQiOjEsImlhdCI6MTc4NjExNzQ3MiwiZXhwIjoxNzg2MjAzODcyfQ.OxsS9piuwWwG5PZNnkh-dqBJIb93UOGhDFF0cJ4aUYCqqOEUEFZreh-dta0LmsUb" -d '{"incidentId":1,"resourceId":1,"hospitalId":1}'

সক্রিয় জরুরি অ্যাসাইনমেন্টের তালিকা দেখতে:

Expected Output (HTTP 200 OK):
List of active disaster dispatch assignments across all regions.
