Microservice Architecture

Decoupled, event-driven services communicating via internal secure network mesh.

🏗️ Core Microservices Breakdown
  • 🔹 API Gateway: Sole public ingress point & OAuth2/JWT auth filter.
  • 🔹 Intake Service: Continuous GeoJSON & event streaming into Kafka.
  • 🔹 Resource Tracker: Dynamic GPS, hospital capacity & maintenance state.
  • 🔹 Optimization Engine: Multi-factor scoring & constraint solver.
Security & Ingress Justification:
"Each microservice is independently deployable and isolated. The API Gateway serves as the single ingress point, ensuring all internal microservices communicate exclusively over a private network with mTLS and role-based access control."
